# Spellgems

Minecraft magic mod for Fabric and NeoForge. Combat and utility spells live on gems you cast manually or automatically.

## Setup

JDK 25.

### Datagen

```bash
./gradlew :fabric:runDatagen
```

### Run

```bash
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```
